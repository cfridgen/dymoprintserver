# v1.5 Feature Plan (DYMO Connect Parity)

## Quelle / Referenz
Die folgende Planung basiert auf den offiziellen DYMO Help-Artikeln:
- https://help.dymo.com/s/article/How-to-use-DYMO-Connect-for-Desktop?language=en_US
- https://help.dymo.com/s/article/How-to-use-DYMO-Label-Software-v-8?language=en_US
- https://help.dymo.com/s/article/How-do-I-print-labels-from-3rd-party-platforms?language=en_US

## Ziel
In v1.5 soll dymoprintserver den DYMO-Connect-Funktionsumfang fuer Label-Design und Druck moeglichst vollstaendig abdecken, mit Schwerpunkt auf lokalem USB-Betrieb und API-Automatisierung.

## Muss in v1.5 (vom Nutzer gefordert)
- Schriftarten (TrueType, Groesse, Stil)
- Kleine Bilder
- Formen
- Rahmen um Text
- Datum
- Uhrzeit
- Datum+Uhrzeit
- Zaehler mit Startnummer, Intervall, Endnummer
- Barcodes in verschiedenen Kodierungen
- QR-Codes
- Visuell auffaellige Vorlagen

## DYMO-Connect-Paritaet: Feature-Katalog

### A. Layout- und Text-Engine
- Textobjekte (mehrzeilig)
- Adressobjekte
- Horizontale/vertikale Textausrichtung
- Font-Familie (TrueType), Font-Size, Fett/Kursiv/Unterstrichen
- Textausrichtung links/zentriert/rechts
- Rahmen/Borders pro Objekt
- Padding und Innenabstand
- Formen: Linie, Rechteck, abgerundetes Rechteck, Kreis
- Layer-Reihenfolge (vorn/hinten)

### B. Datenobjekte und dynamische Felder
- Datum (heute)
- Uhrzeit (jetzt)
- Datum+Uhrzeit
- Zaehlerobjekt:
  - start
  - interval/step
  - end
  - optionales Prefix/Suffix
  - optionales Zero-Padding
- Serien-/Batch-Druck aus Datensaetzen

### C. Codes
- Barcode-Objekt mit Typwahl (mindestens):
  - Code 39
  - Code 128 A/B/C + Auto
  - EAN-8
  - EAN-13
  - UPC-A
  - UPC-E
  - ITF14
  - Codabar
  - PDF417
  - GS1 DataMatrix (square/rect)
  - Intelligent Mail (optional: US)
- QR-Code-Objekt mit Inhaltstypen:
  - text
  - url
  - phone
  - email
  - sms
  - vcard

### D. Medien
- Bildobjekt (BMP/GIF/JPG/PNG/TIFF)
- Bild skalieren/fitten/croppen/rotieren
- PDF-Seite als Bild importieren (optional v1.5.x)

### E. Vorlagen und Projekte
- Template speichern/laden/exportieren
- Vorlagenkategorien:
  - Versand
  - Adresse
  - Inventar
  - Preisetikett
  - Warnhinweis
  - Kabel/Band
- Visuell auffaellige Templates:
  - starke Kontraste
  - Icon + Text + Code
  - Badges/Flags

### F. Datenimport / Kontakte
- CSV-Import
- XLSX-Import
- Feldzuordnung (Mapping) auf Objekt-Properties
- Mehrfachdruck ueber Datensatzliste
- Kontakte lokal speichern (Adressbuch)
- Optional: Outlook/Google Import Connector (spaeter)

### G. Druck- und Job-Features
- Printer-/Bandprofil pro Template
- Vorschau mit kalibriertem 12-mm-Vorlauf
- Feste Labelgesamtlange (z. B. 40 mm) pro Profil
- N-up/Batch Jobs
- Job Queue + Retry
- Druck-Historie

### H. Web-UX (Editor)
- WYSIWYG Canvas
- Objekt-Toolbar (Text/Bild/Barcode/QR/Form)
- Property-Panel rechts
- Grid + Snap
- Undo/Redo
- Keyboard-Shortcuts

## Technische Abgrenzung fuer v1.5
- Fokus bleibt lokal-first (USB direkt am Host)
- Kein Cloud-Zwang
- Keine Abhaengigkeit von DYMO Connect Web Service
- LabelWriter-spezifische 4x6-Workflows nur optional/sekundaer

## Release-Schnitt fuer v1.5

### v1.5.0 (Core Designer)
- Text, Fonts, Rahmen, Formen
- Datum/Uhrzeit
- Barcode + QR (Grundtypen)
- 3-5 visuelle Templates

### v1.5.1 (Counter + Batch)
- Counter-Objekt mit Start/Intervall/Ende
- CSV/XLSX Import + Mapping
- Batch-Print

### v1.5.2 (Media + Advanced Codes)
- Bildimport + Crop/Fit
- Erweiterte Barcode-Typen (PDF417, DataMatrix, IMb optional)

### v1.5.3 (Pro UX)
- Undo/Redo
- Grid/Snap
- Template-Bibliothek erweitert
- Druck-Historie/Queue

## Akzeptanzkriterien (v1.5 Gesamt)
- Jede Funktion in Muss-Liste ist per UI und API nutzbar
- Jede Funktion druckt reproduzierbar auf LabelManager PnP
- Vorschau und Druck sind kalibriert (12-mm-Vorlauf beruecksichtigt)
- Mindestens 10 Templates im Repo
- Dokumentation mit Beispielen je Objekt-Typ
